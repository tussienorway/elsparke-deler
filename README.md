# Elsparke-deler

Norsk, statisk nettside om gjenbruk og kombinasjon av deler fra elsykler og elsparkesykler: display (som King-Meter KM529), styrepanel, kontroller, batteri, plugger (Julet/Higo) og måling med multimeter.

**Nettside:** https://tussienorway.github.io/elsparke-deler/

## Innhold

- Hva som passer sammen, og hva som ikke gjør det (spenning, strøm, protokoll, pinnerekkefølge)
- Display og protokoller (King-Meter, KT, Bafang, Xiaomi/Ninebot)
- Plugger og fargekoder, batteri, BMS og lader
- Sparkesykler (Hiley, Xiaomi/Ninebot) og hvorfor deler fra delesparkesykler (Voi o.l.) er uaktuelle
- Multimeter steg for steg, sjekkliste, sikkerhet, norske regler og ordliste
- «AI-hjelp»: en enkel veileder (beslutningstre) som kjører lokalt i nettleseren, uten API-nøkler

Alle påstander har kilder nederst på siden. Ting vi ikke har funnet kilde for, er merket «usikkert».

## Filer

- `index.html`, `style.css`, `app.js` – selve siden (ren HTML/CSS/JS)
- `REVIEW.md` – kritisk gjennomgang av første utkast og hva som ble rettet

## Forbehold

Hobbyprosjekt, ikke juridisk eller elektroteknisk rådgivning. Litium-batterier kan ta fyr. Følg rådene fra DSB.
